# 💳 Banco Digital em Java

Projeto pessoal desenvolvido com o objetivo de praticar desenvolvimento backend, criação de APIs REST e integração com banco de dados utilizando Java puro.

---

## 🚀 Tecnologias Utilizadas

- Java
- Servidor HTTP nativo
- SQLite
- HTML e CSS
- Git e GitHub

---

## 📌 Funcionalidades

- Cadastro de usuários
- Login
- Persistência de dados com SQLite
- Integração backend + frontend
- Estruturação manual de servidor HTTP

---

## 🛠 Como executar o projeto

1. Clone o repositório: git clone https://github.com/Picykico/banco-digital.git
2. Abra o projeto na sua IDE (NetBeans, IntelliJ ou similar)
3. Execute a classe principal do servidor
4. Acesse no navegador: http://localhost8080

---

## 🎯 Objetivo do Projeto

Este projeto foi criado para aprofundar conhecimentos em:

- Programação Orientada a Objetos
- Funcionamento do protocolo HTTP
- Estruturação de APIs REST
- Organização de projetos backend
- Versionamento com Git
